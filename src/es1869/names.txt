# Names and hints for ES1869.DRV 4.04.00.1319, read by tools/ne2asm.py

#   seg:off kind name [size] ; comment
#
# kinds: code (an entry point), data (bytes, with a size), var (a DGROUP
# variable, absolute operands [off] use the name), imm (the immediate of
# the instruction at seg:off is the offset of label <name>), label (a name,
# and on a jump table the size is the number of entries)
#
# ESS's wave, mixer and aux driver: wave-out plays on Audio 2, wave-in
# records on Audio 1. docs/DRIVER_CONFIG.md and docs/VXD_API.md list what
# its routines read, write and call. The Windows 95 DDK's MSSNDSYS sample
# (MMEDIA\SAMPLES\MSSNDSYS\DRV) has the same design: the VxD hands out the
# hardware and the DMA buffers, this driver runs the devices.
