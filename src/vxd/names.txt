# Symbol names and disassembly hints for ES1869.VXD (tools/vxd2asm.py)

# format:  obj:offset  kind  name  [size]  [; comment]
#   kind  code    code entry point (label + follow it as code)
#         label   label only
#         data    label; the next <size> bytes are data (never decoded as code)
#         ddb     the VxD_Desc_Block (formatted field by field)
#         client  <size> bytes of code whose [ebp+n] operands are Client_Reg_Struc
#         ctlmsg  <size> bytes of code comparing EAX with control message numbers
# Offsets are relative to the LE object (o1 = LCOD ... o7 = ICOD).  Names of the
# no-DMA ("ND") routines come from the COFF symbol table of nodma.obj that the
# linker left in the file's unused pages 15-21 (anchored _PTEXT = o5:24D0,
# PNP = o4:0C60, abNDOneOpndBypass = o1:02F4).
