# ES1869 registers

This reference is generated by `tools/regdoc.py` from the catalog
`src/esscat.tbl`, so edit the catalog rather than these pages. Page numbers
refer to the ES1869 data sheet, `docs/datasheet/es1869techmanual.pdf`.

The catalog has 147 registers with 299 settings, and profiles store 56 of
the settings. The registers are split over three pages, because Windows 98's
Notepad can't open a file of 64 KB:
* [The mixer registers](REG_MIXER.md)
* [The controller registers and audio ports](REG_AUDIO.md)
* [The configuration ports and PnP registers](REG_PNP.md)

Each register lists its data sheet page, and then its settings. A setting
starts with its bits and its name, followed by its key in essctl's profiles,
its kind, its tier and its flags, and then its description.

The tier decides what essctl lets you change:
* *safe* settings are ordinary ones.
* *caution* settings can mute, distort or confuse Windows' driver, but can't
  hang anything.
* *expert* settings can stop playback, hang the DSP until the next reset, or
  move the card to other resources, so essctl changes them only in Expert
  mode.
* *read-only* settings are status, and are never written.

The flags say more about a setting:
* *profile*: File > *Save profile* and `essctl /save` store it.
* *driver sets it*: ES1869.DRV or ES1869.VXD rewrites it, and a profile
  loaded at startup puts it back.
* *reset by DSP reset*: a DSP reset sets it back, and the driver resets the
  DSP whenever the device changes hands.
