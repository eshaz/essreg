# ES1869 registers

Generated by `tools/regdoc.py` from `src/esscat.tbl`; do not edit.
Page numbers refer to the ES1869 data sheet in `docs/datasheet/es1869techmanual.pdf`.

133 registers, 272 fields, 50 stored in profiles.

**Tiers** decide what essctl lets you change:

| Tier | Meaning |
|---|---|
| safe | ordinary settings |
| caution | can mute, distort or confuse Windows' driver, but not hang anything |
| expert | can stop playback, hang the DSP until the next reset or move the card to other resources; needs Expert mode |
| read-only | status, never written |

**Flags:** *profile* = saved by File > Save profile and `essctl /save`; *driver sets it* = ES1869.DRV or ES1869.VXD rewrites it (a profile loaded at startup puts it back); *cleared by DSP reset* = lost when the DSP is reset, which the driver does whenever the device changes hands.
